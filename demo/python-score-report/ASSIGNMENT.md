# Demo assignment: Mini score report

Complete `main.py` using the provided student scores.

## Requirements

1. Print one line for each student in the form `Name: score`.
2. Calculate and print the class average rounded to one decimal place, in the
   form `Average: 83.0`.
3. Use a loop. Do not install packages or ask the program to read input.

Run the program in VS Code's integrated terminal with `python main.py` (or
`py main.py` on Windows if `python` is not available).

For the tutor demonstration, ask a narrow syntax question such as how to format
a floating-point number to one decimal place. Write and run the solution
yourself; the tutor is configured to give syntax/reference help rather than
solve the assignment.
